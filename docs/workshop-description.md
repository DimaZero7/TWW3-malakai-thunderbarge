# Описание мода для Мастерской

Черновик. Полное описание напишем перед публикацией.

## Совместимость

- **Требуется:** memreader Plus.
- **Нужна новая кампания:** старые сейвы не поддерживаются.
- **Не работает с MIXER - Mixu's Unlocker:** с ним игра падает на первом конце хода. Это происходит и без нашего мода, поэтому выключите его на время игры.

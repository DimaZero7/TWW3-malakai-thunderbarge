# Вопросы пользователю

Решения, которые принял агент ночью вместо вас. Всё обратимо.

## 1. Фигура гнома у носа барки

Гном-истребитель у носа — часть стоковой анимации Духа Грунгни, а не боец и не место экипажа. Он остаётся на пустой барке. Записан в метаданных анимации корпуса как `ANIMATED_PROP`. Он есть и на стоковой барке.

Убрать за несколько попыток не удалось, все варианты в `docs/design/modular-crew.md`. Сейчас он **оставлен**: `remove_bow_figure` = false в `data/crew_options.json`.

**Вопрос:** оставить как украшение или добиваться удаления, например через таблицу анимации из AssetEditor?

## 2. С чего начинают игрок и ИИ

По плану старт с пустых отсеков. В конфиге сейчас `start: stock`, чтобы барка не пустела, пока нет построек и интерфейса. Меняется одной строкой на группу. Правила прогрессии для ИИ-Малакая нет: он получает то же начальное значение.

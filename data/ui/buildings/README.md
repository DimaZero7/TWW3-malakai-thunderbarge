# Значки построек барки

Рисует `tools/draw_building_icons.py`. Формат как у `ui/buildings/icons/dwarf_spirit_of_grungni_*.png`: 74×74 RGBA, ровный цвет в RGB, рисунок в альфе, не больше 204. Плитку с обгорелым краем (`building_frame.png`) и вид «доступно/недоступно» делает интерфейс, поэтому отдельных серых версий нет: у игры их тоже нет.

`contact-sheet.png` нужен только для проверки, в пак его не класть.

Имя файла это короткий ключ уровня из `data/crew_options.json`, полный ключ в таблицах: `wh3_dlc25_dwarf_spirit_of_grungni_` + короткий.
